# git-homework

Учебный репозиторий для практики работы с Git и GitHub.

## Содержимое

- `README.md` — описание проекта.
- `index.html` — HTML-страница с Hello World.

## Что отрабатывается

- создание удалённого репозитория;
- клонирование репозитория;
- первый коммит и push;
- несколько дополнительных коммитов;
- просмотр истории и состояния через `git log` и `git status`.
